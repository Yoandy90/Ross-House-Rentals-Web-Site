📋 Resumen Ejecutivo

RossTax API v3.0 es la reimplementación completa del plugin de integración entre Rise CRM y la aplicación Ross Tax Preparation. Esta versión corrige todos los problemas de la v2.0 y proporciona una integración robusta y completamente funcional.

✅ ¿Por qué v3.0?
La versión anterior (v2.0) no se cargaba correctamente en Rise CRM debido a problemas de arquitectura. La v3.0 ha sido completamente reconstruida siguiendo las mejores prácticas de CodeIgniter 4 y los patrones de plugins funcionales de Rise CRM.

🚀 Instalación Rápida

1 Descargar y Extraer

Descarga el archivo ZIP y extráelo en tu computadora. Verifica que la carpeta se llame exactamente RossTaxAPI.

2 Subir via FTP

Conecta via FTP a tu servidor y sube la carpeta RossTaxAPI a:

/public_html/plugins/RossTaxAPI/

Estructura final: /plugins/RossTaxAPI/index.php

3 Activar en Rise CRM

En Rise CRM, ve a: Settings → Plugins

Busca "RossTax API" y haz clic en "Activate"

4 Generar Token

En el menú lateral, haz clic en "RossTax API"

Genera un nuevo token API y guárdalo de forma segura

5 Configurar Ross Tax

Actualiza el archivo /app/backend/.env con el token generado:

RISE_CRM_API_TOKEN=

Reinicia el backend: sudo supervisorctl restart backend

6 Verificar Funcionamiento

Prueba la conexión ejecutando:

curl -X POST http://localhost:8001/api/rise-crm/test-connection

Debe retornar: {"success": true, "message": "Successfully connected to Rise CRM API"}

⚠️ Nota Importante:
Si la instalación via FTP falla, puedes usar cPanel File Manager o activación manual via phpMyAdmin. Consulta la Guía de Instalación Completa para métodos alternativos.

🔍 Endpoints API Disponibles

🧪 Test

GET /rosstax_api/test

👥 Clientes

GET /rosstax_api/clients GET /rosstax_api/clients/{id} POST /rosstax_api/clients PUT /rosstax_api/clients/{id} DELETE /rosstax_api/clients/{id}

📁 Proyectos

GET /rosstax_api/projects GET /rosstax_api/projects/{id} POST /rosstax_api/projects PUT /rosstax_api/projects/{id} DELETE /rosstax_api/projects/{id}

✅ Tareas

GET /rosstax_api/tasks GET /rosstax_api/tasks/{id} POST /rosstax_api/tasks PUT /rosstax_api/tasks/{id} DELETE /rosstax_api/tasks/{id}

🎫 Tickets

GET /rosstax_api/tickets GET /rosstax_api/tickets/{id} POST /rosstax_api/tickets PUT /rosstax_api/tickets/{id} DELETE /rosstax_api/tickets/{id}
💡 Tip:
Todos los endpoints requieren autenticación mediante token API en el header:
Authorization: Bearer {tu-token}

✅ Verificación de Instalación

Una vez instalado, verifica que todo funcione correctamente:

  1. El plugin aparece en el menú lateral como "RossTax API"
  2. Puedes acceder al panel administrativo
  3. Puedes generar tokens API
  4. Los endpoints devuelven respuestas correctas (no 404)
  5. Los logs registran las solicitudes
