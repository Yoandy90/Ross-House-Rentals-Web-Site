⚡ Quick Start (5 Minutes)

1 Upload Controller

Upload Rosstax_api.php to your Rise CRM server:

/app/Controllers/Rosstax_api.php

Via FTP: Connect to your server and upload to the path above

Permissions: Set to 644 (rw-r--r--)

2 Create Database Tables

Execute the database.sql script in phpMyAdmin:

CREATE TABLE IF NOT EXISTS `rise_rosstax_api_tokens` ( `id` int(11) NOT NULL AUTO_INCREMENT, `token` varchar(255) NOT NULL, `is_active` tinyint(1) DEFAULT 1, `created_at` datetime DEFAULT NULL, `last_used_at` datetime DEFAULT NULL, PRIMARY KEY (`id`), UNIQUE KEY `token` (`token`) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

3 Generate API Token

Create a secure token in your database:

INSERT INTO rise_rosstax_api_tokens (token, is_active, created_at) VALUES ('rosstax_prod_2025_YOUR_SECURE_TOKEN', 1, NOW());

💡 Tip: Generate a strong random token (32-64 characters)

4 Test Installation

Open in your browser:

https://your-rise-crm-domain.com/index.php/rosstax_api/test

Expected response:

{ "success": true, "message": "RossTax API is working!", "version": "3.0.0" }

5 Configure Your Application

Add to your application's .env file:

RISE_CRM_URL=https://your-rise-crm-domain.com RISE_CRM_API_TOKEN=rosstax_prod_2025_YOUR_SECURE_TOKEN
🎉 Done!
Your API is now ready to use. Test it with:
curl -H "Authorization: Bearer YOUR_TOKEN" \ https://your-domain.com/index.php/rosstax_api/clients

💡 Usage Examples

cURL

# Get all clients curl -H "Authorization: Bearer YOUR_TOKEN" \ https://domain.com/index.php/rosstax_api/clients # Create new client curl -X POST \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{"company_name":"John Doe","email":"john@example.com"}' \ https://domain.com/index.php/rosstax_api/create_client

JavaScript

fetch('https://domain.com/index.php/rosstax_api/clients', { headers: { 'Authorization': 'Bearer YOUR_TOKEN' } }) .then(r => r.json()) .then(data => console.log(data));

🛠️ Troubleshooting

404 Not Found?
• Verify file location: /app/Controllers/Rosstax_api.php
• Check file permissions: 644
• Clear Rise CRM cache
• Restart web server
401 Unauthorized?
• Verify token exists in database
• Check token is active (is_active = 1)
• Verify header format: Authorization: Bearer TOKEN

🔒 Security Best Practices

  • ✅ Always use HTTPS in production
  • ✅ Generate strong random tokens (32+ characters)
  • ✅ Rotate tokens periodically
  • ✅ Monitor API logs for suspicious activity
  • ✅ Keep tokens secret - never commit to version control
  • ✅ Set is_active=0 to immediately revoke a token
