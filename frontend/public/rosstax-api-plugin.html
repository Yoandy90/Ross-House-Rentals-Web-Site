📋 Installation Steps

Upload Plugin to Rise CRM

Go to Settings → Plugins → Install plugin and upload the downloaded ZIP file.

Activate the Plugin

Find "RossTax API" in the plugins list and click Activate. The plugin will automatically create the necessary database tables.

Configure API Token

Insert your existing API token into the database:

INSERT INTO rise_rosstax_api_tokens 
(user_id, token, name, created_at, is_active) 
VALUES 
(1, 'YOUR_TOKEN_HERE', 'Ross Tax App', NOW(), 1);

Replace YOUR_TOKEN_HERE with your Rise CRM API token.

Test the Connection

Verify the API is working:

curl https://admin.rosstaxpreparation.com/index.php/rosstax_api/test
ℹ️ Important: All API requests must include the authtoken header with your API token.

🔌 API Endpoints

Clients

GET /index.php/rosstax_api/clients
GET /index.php/rosstax_api/clients/{id}
POST /index.php/rosstax_api/clients
PUT /index.php/rosstax_api/clients/{id}
DELETE /index.php/rosstax_api/clients/{id}

Projects (Appointments)

POST /index.php/rosstax_api/projects - Create appointment/project
GET /index.php/rosstax_api/projects - List all projects

Tasks (Documents)

POST /index.php/rosstax_api/tasks - Create document task
GET /index.php/rosstax_api/tasks - List all tasks

Tickets (Service Requests)

POST /index.php/rosstax_api/tickets - Create service request ticket
GET /index.php/rosstax_api/tickets - List all tickets

💻 Example Usage

Create a new client:

curl -X POST https://admin.rosstaxpreparation.com/index.php/rosstax_api/clients \
  -H "authtoken: YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "company_name": "John Doe",
    "phone": "+1234567890",
    "address": "123 Main St",
    "city": "Austin",
    "state": "TX",
    "zip": "78701"
  }'
⚠️ Troubleshooting 403 Errors:

If you receive 403 Forbidden errors, this is likely a server firewall issue (not the plugin). Contact your hosting provider (SiteGround) to whitelist your IP address for API access.
